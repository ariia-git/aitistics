# Methodology

Aitistics records repeatable AI-video experiments and aims to preserve enough information to understand or reproduce each test where practical.

Retain original generator configuration where available, representative frames, relevant metadata, and final video links. Preserve source filenames and contents unless privacy requires a documented change.

Record only facts supported by available artefacts. Distinguish configured settings from measured output, identify inferred dates, and leave unknown optional fields blank. Exact reproduction may depend on software versions, models, hardware, or other unrecorded details.

Organise runs by generation system with independent numbering per system. Use relative references, keep rendered videos outside Git, and review settings and documentation for secrets and machine-specific paths before public release.
